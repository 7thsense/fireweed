# Contributing to Fireweed Queue

Fireweed Queue is a maintainer-developed open-source project. We welcome
issues, but we do not accept pull requests, patches, or other code
contributions.

## Issues are welcome

Please open an issue for:

- bugs;
- feature requests;
- documentation problems; or
- compatibility reports.

Do not report security vulnerabilities in a public issue. Use the repository's
private security-reporting channel instead.

If an issue includes material from a third party, identify its source and
license. Keep reproduction snippets small. Do not submit material that you do
not have permission to share.

Unless you explicitly state otherwise, small original snippets or authorized
reproduction snippets that you intentionally submit in an issue for possible
incorporation into Fireweed Queue are offered under the repository's
`MIT OR Apache-2.0` license, without additional terms or conditions.

## Code contributions are closed

Pull requests, patch files, and branch- or fork-based code submissions are not
accepted. Please use an issue to describe a proposed change rather than
implementing it for submission.

No Contributor License Agreement (CLA) or Developer Certificate of Origin
(DCO) applies while code contributions remain closed.

## Questions and support

Search the documentation and existing issues first. If they do not answer your
question, open an issue with the Fireweed Queue version, the relevant storage
backend, what you expected, and what happened. Support is provided on a
best-effort basis; maintainers do not guarantee a response or resolution time.

See [SUPPORT.md](SUPPORT.md) for the support boundary. Follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) in project discussions. Security
vulnerabilities must be reported privately as described in
[SECURITY.md](SECURITY.md), never as a public support issue.
