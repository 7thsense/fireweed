OWNER=<github-owner>
REPO=pqueue
TAG=v0.2.3
VERSION="${TAG#v}"
DIST_DIR="release-${TAG}"

gh release download "$TAG" --repo "${OWNER}/${REPO}" \
  --pattern "pqueue-${VERSION}-*.tar.gz" \
  --pattern "pqueue-${VERSION}.tgz" \
  --pattern "pqueue-service-image.txt" \
  --pattern "pqueue-helm-chart.txt" \
  --pattern "SHA256SUMS" \
  --dir "$DIST_DIR"

(cd "$DIST_DIR" && shasum -a 256 -c SHA256SUMS)
helm install postgres_native 
NAMESPACE=pqueue
RELEASE=pqueue
IMAGE="ghcr.io/${OWNER}/pqueue-service"

kubectl create namespace "$NAMESPACE"
kubectl -n "$NAMESPACE" create secret generic pqueue-postgres \
  --from-literal=database-url='postgres://pqueue:pqueue@postgres.example:5432/pqueue'

helm install "$RELEASE" "$DIST_DIR/pqueue-${VERSION}.tgz" \
  --namespace "$NAMESPACE" \
  --set image.repository="$IMAGE" \
  --set image.tag="$VERSION" \
  --set backend.profile=postgres_native
kind smoke local proof 
bash scripts/ci/helm-gate.sh
bash scripts/ci/kind-helm-test.sh --backend postgres_native
bash scripts/ci/kind-helm-test.sh --backend object_log_sqlite_projection

Backend Profiles

BUILD-001 scope

postgres_native

Reference correctness backend. Requires PostgreSQL Secret pqueue-postgres with key database-url.

object_log_sqlite_projection

Postgres control plane, S3-compatible object log, and PVC-backed SQLite projection. The local production proof must use MinIO and verify restart/replay.

Production Status

release gated

target postgres_native

Production-readiness claim needs release artifact verification, Helm static validation, and a passing kind install/upgrade/uninstall smoke for that release.

target object_log_sqlite_projection

Do not overclaim cloud S3 certification. Current production scope is MinIO S3-compatible proof only, including bucket setup, object-log writes, restart/replay, and SQLite recovery in kind.
