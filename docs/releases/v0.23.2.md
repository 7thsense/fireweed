# Fireweed Queue v0.23.2 public preview

v0.23.2 ships the **complete public 5×3 storage matrix**: every log × projection
cell opens, runs, and is covered by the release storage-matrix gate.

## Storage matrix (complete)

Public logs: `memory`, `sqlite`, `postgres`, `filesystem`, `s3`  
Public projections: `memory`, `sqlite`, `postgres`

- Normative construction is `StorageConfig` + `open` / `open_async`.
- Class A (durable logs) and Class B (`memory` log) durability semantics are
  documented and enforced in conformance helpers.
- Public product surface rejects legacy profile names (`objectlog`, `inmemory`,
  hybrid/turso projection select).
- Preview boundary lists all **15 cells as supported** (Class B carries a
  semantic durability disclaimer only).

## Verification

- `scripts/ci/storage-matrix-gate.sh` binds the matrix (library T0–T2 for all 15
  cells with live Postgres + S3-compatible fixtures when
  `FIREWEED_STORAGE_MATRIX_REQUIRE_FULL=1`).
- Helm CI values cover the full matrix; helm static validation is part of the gate.
- `scripts/ci/assert-no-legacy-storage-product-names.sh` keeps public surfaces clean.
