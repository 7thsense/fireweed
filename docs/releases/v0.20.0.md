# Fireweed Queue v0.20.0 public preview

v0.20.0 is the first public preview release under the Fireweed Queue identity.
It begins the additive namespace migration defined by
[ADR-020](../helix/02-design/adr/ADR-020-public-namespace-and-compatibility.md):
new public-facing coordinates move to Fireweed names while compatibility and
durable identifiers remain available according to the migration policy.

v0.19.6 and earlier retain the pqueue identity in release tags, release notes,
artifacts, audit records, bead IDs, and branch history. Those historical names
are part of the project's traceable release lineage and are not rewritten by
the Fireweed Queue rename.

## Changed

- The public display name is Fireweed Queue, with Fireweed as the short name.
- The first renamed release is versioned v0.20.0.
- Existing `pqueue` package, binary, CLI, and environment names remain
  compatibility aliases through the v0.20.0 cutover.
- The source Helm chart remains independently versioned for development. The
  v0.20.0 release package overrides its chart and application versions to
  `0.20.0`; its `pqueue` path, chart, package, and evidence names remain
  compatibility aliases under ADR-020.
- Persisted data names and wire identifiers remain stable unless a separate
  data-migration decision explicitly authorizes changing them.
- Historical release and audit identifiers remain unchanged for traceability.

## Compatibility

The rename is additive for consumers. Follow ADR-020 and the public namespace
migration inventory for the authoritative classification of renamed,
compatibility, intentionally retained, and historical surfaces. Do not infer a
storage or protocol migration from the Fireweed Queue branding change.
