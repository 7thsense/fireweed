# Fireweed Queue v0.29.4

Patch release cut to give Snorri a tag to pin instead of a bare rev. Snorri's
`Cargo.toml` had been pinned at rev `297ad9b9` (3 commits past `v0.29.3`) with
a "restore tag pin at next release" note; no tag covered that rev, so the pin
stayed a rev. This release closes that gap.

## Why this matters downstream

Cayce pins Snorri v0.15.0, whose Postgres workflow-state path panics under
async ("Cannot start a runtime from within a runtime" at
`postgres-0.19.14/src/connection.rs:66`) because Fireweed v0.29.2 used
`InProcessProjectionStore<PostgresRelational>`, which calls the sync Postgres
client inline on a Tokio task. `v0.29.3` already carried the fix — the
async-pure `AsyncObjectLogPostgresBackend` (holding
`AsyncPostgresRelationalProjection`) plus `open_postgres_runtime_async` — and
this release keeps that fix in an addressable tag.

## Highlights since v0.29.3

- **Postgres/Turso matrix Tokio hardening** — drop `Client` off the Tokio
  thread to avoid nested-runtime panics; open S3×Turso and Postgres×Turso
  matrix cells without nesting a runtime inside a runtime
  (`fireweed-core`/`fireweed-postgres`).
- **Envelope encoding** — base64-encode envelope byte fields (~1.33x vs
  4.28x expansion) (`fireweed-659490cc`).
- **Claim selection** — Pending-only claim secondary index for O(claimed)
  selection instead of O(corpus) (`fireweed-cd0e5255`).
- **S3 object-log** — native-CAS emission cursor and P8cs emitter arms
  (`fireweed-cd2e6466`).
- **Operator plane** — API-002 repair/redrive plane and AC-E2E-7
  (`fireweed-c583a697`).
- **Storage** — async nonblocking + bounded sync epoch bridge contracts
  (`fireweed-61324c64`); P11 T3/TP-003 evidence and lease rehydrate fixes
  (`fireweed-38bd4c7a`).
- **Performance** — TP-005 20-cell log/projection matrix instrument via
  `StorageConfig`; provider-neutral E3 guards (`fireweed-02e212c6`).
- **Turso** — `BatchUpdatePort` and the `fireweed-million-cycle` binary.
- **CI** — GitHub Actions policy and repository-side governed proof
  (`fireweed-5ef8ed0c`); sole final governed-product allowlist
  (`fireweed-7d2407dd`).

## Scope note

This is a tag-only patch release off the last commit still carrying the
`0.29.x` package identity. It does not include the `0.30.0` identity-freeze
line (`docs/releases/v0.30.0.md`, P17v) — that tag remains reserved until
storage-campaign product-ready (`P20pr`) per that note's policy, and is out
of scope here.
