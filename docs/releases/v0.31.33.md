# Fireweed v0.31.33 — integrated queue work and bounded append preparation

This source-preview release incorporates the queue source-selection work landed
since v0.31.32 and fixes a packed append epoch read that ran outside the
pre-position deadline. Epoch validation now runs once inside the timed metadata
permit. Regression tests cover timeout before publication, cancellation and retry,
exact apply debt, independent publication signals, and post-position poison.

## Integration

- Merge the publication fix and outstanding-work reconciliation with their
  original commit history.
- Integrate the ten dependency branches. Keep already-landed axon-esf 0.4.2,
  heimq 0.1.6, and the newer Rust 1.99.0 toolchain.
- Update current workflows to checkout v7 and Helm 4.2.3, the runtime image to
  Ubuntu 26.04, and the development Compose image to PostgreSQL 18. Compose uses
  a fresh `fireweed-postgres18-data` volume mounted at `/var/lib/postgresql`;
  existing PostgreSQL 16 volumes require an explicit database migration.
- Preserve the older Turso port branch in merge history while retaining the
  current recovery, mutation, query, and commit implementations.
- Replace the deleted `all_four_log_specs_accept_turso` CI selector with
  `s3_turso_is_the_public_env_cell`, including its governance route binding.
- Align the E2 container build with Rust 1.99.0.
- Recover the readable storage research branch, including SPIKE-002 through
  SPIKE-006 and its original experiments. Preserve current contracts and mark
  API-006/ADR-025 as superseded by API-007/ADR-026. Record the completed
  SPIKE-002 key-lookup trace.

## Security maintenance

- Update `aws-sigv4` to 1.6.4, bringing `crypto-bigint` 0.7.10 and the corrected
  P-256 implementation, and update `ctutils` to 0.4.8.
- Update `rustls-webpki` to 0.103.16 and `webpki-root-certs` to 1.0.11.
- Update Tokio to 1.54.1, `zstd` to 0.13.4, `zstd-safe` to 7.4.0, and
  `zstd-sys` to 2.1.2.
- Retain an identified informational maintenance exception for the archived
  `pin-utils` 0.1.1 macro dependency until upstream AWS removes it. Actual
  vulnerability checks remain enabled.
- Classify 42 historical scanner findings as source-file SHA-256 digests with
  exact history fingerprints. Credential source files and the rest of history
  remain scanned.

The rescue snapshot `80b7651a531d5450f74432ebc1c65a419126fc0c` is excluded:
all 115 modified files contain invalid UTF-8, including source scripts and
historical evidence. The original rescue branch retains the snapshot for
recovery. It cannot provide reviewable implementation changes for this release.

## Qualification

qualification, signing, container publication, or new capacity measurements.

`0.31.33`. Helm source defaults, the independent benchmark tool, and gate-set

```sh

bash scripts/release/verify-release-identity.sh --version 0.31.33
```
