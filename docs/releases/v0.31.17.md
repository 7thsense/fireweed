## Headline

SQL projections lease work in one database transaction and then record the
Claim on the object log. The SQL projection is the item store, including
payloads. The in-process planner map is gone.

## Cut contents

- Shared `fireweed_claim_outbox` and `fireweed_lease_bearers` schema.
- Class S claim: select due rows + payloads, lease, outbox, commit, then log PUT.
- Claim apply and fused claim+complete are idempotent (no shard poison).
- `LeaseExpired` cannot unlease a still-live Class S claim.
- Object-log × Turso claim no longer waits for apply of that Claim to return bodies.
- SQLite and Postgres claim paths write the same outbox contract.
- Process `live_tokens` is not the serving authority; bearer tokens live in SQL.
