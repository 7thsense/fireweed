# Fireweed Queue v0.23.1 public preview

v0.23.1 completes the native-S3 storage-matrix conformance coverage that
landed immediately after v0.23.0.

## Native S3 matrix

- Adds S3 × memory, SQLite, and Postgres projection matrix fixtures, Helm CI
  values, and transaction evidence.
- S3 object-log startup requires native atomic conditional creation; it does
  not add a Postgres manifest authority. Garage is eligible only when it
  passes that capability and recovery/fencing checks.
- Postgres remains available as a selected projection or queue-control-plane
  backend, independently of S3 object-log authority.

## Publication boundary

This remains a source release under `MIT OR Apache-2.0`. The live Garage E3
proof remains pending rotated dedicated credentials and an isolated test
bucket/prefix; no release evidence is fabricated.
