# pqueue v0.17.2

## Fixes

- Embedded object-log plus SQLite verification now checkpoints every already-admitted asynchronous
  projection batch before comparing SQLite with the authoritative log. This closes a lifecycle race in
  which an immediate verification could observe log sequence 1 while SQLite was still at sequence 0.
- The checkpoint barrier is verification-specific. Projection deletion and rehydration can still discard
  deferred work and rebuild from authoritative history, including recovery from a poisoned checkpoint.

## Release workflow

- The tag workflow now executes the source release gate exactly once as part of the deployment gate. It no
  longer repeats workspace tests, coverage instrumentation, and performance-smoke binaries before the kind
  storage matrix.
- Quiet-host E2 performance evidence is explicitly deferred for v0.17.2. Shared GitHub runners do not run
  the cross-queue scale workload or the 1,000-queue density ladders and cannot satisfy an E2 evidence claim.
  The host-independent E2 evidence-judgment contract still runs.
- Deployment proof records `e2_smoke_status: deferred_quiet_host` and the bound release version. The
  deferral expires by construction: the next version must update the workflow deliberately or the release
  gate fails its identity check.

## Release boundary

- Niflheim remained in service. The governed quiet-host 1,001-queue density diagnostic and release-tier E3
  cost plus 10-million-item recovery measurements remain deferred; this release makes no new performance
  claim from those rows.
- Production governed-tag wiring remains open, and `objectlog/hybrid-strict` remains experimental through
  direct environment or configuration only.
- The workspace MSRV remains Rust 1.92 and no data migration is required.

## Verification

- Warning-denied Clippy, workspace correctness tests, exact Postgres TP003 evidence, live coverage bars,
  build-closure integrity, Helm checks, and the four-combination kind storage matrix remain release gates.
- The deterministic deferred-checkpoint regression passes, and the formerly flaky lifecycle interleaving
  test passes repeated execution.
