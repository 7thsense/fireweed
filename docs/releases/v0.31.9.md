## Headline

Every production typed-index encode path now frames **native `TypedValue`s**.
Lookups, uniqueness, range seeks, and Postgres/Turso persist+echo no longer
build a JSON entity and ask axon to re-parse it. `UpdateFields` rematerializes
`index_fields` when the entity document changes so unique keys move with the
new values.

## Cut contents

- Shared helpers: `typed_index_keys_for_item`, `typed_lookup_key`,
  `framed_typed_value` (`fireweed-engine::index_fields`).
- Admission uniqueness (`unique_index_keys_for_push_item`) encodes from
  `index_fields`.
- Memory, sqlite, Postgres, and Turso lookups use the native framed encoder.
- Range seeks and filtered metrics encode `TypedValue` directly (datetime is
  epoch nanos).
- Postgres / Turso / sqlite persist the `index_fields` blob on insert **and**
  update; claim echo synthesizes the entity from that blob when admission
  dropped the JSON document.
