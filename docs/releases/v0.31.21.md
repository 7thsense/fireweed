## Headline

Class S claim is one SQL lease, then a log fact. Eight inflight claims
group-commit that lease. Live apply of an already-leased Claim is a no-op
plus outbox delete. Deliver is still slower than ingest.

## Cut contents

- Thin Class S SELECT (payloads stay; no fields/metadata; gate anti-join
  only if the queue has blocked gates).
- Already-leased Claim apply skips item UPDATE, bearers, and group relect.
- Inflight=8 P4 waves. The apply coordinator picks a contiguous Ready
  batch even when a later gap was enqueued first (that hang was why
  eight claims were reverted).
- Concurrent Class S waiters share one `IMMEDIATE` (one fsync, not eight).
- Outbox delete is in live Claim apply. The caller does not take the
  Turso writer after enqueue.
- Group-summary member dump is gone; relect is COUNT + LIMIT 1.
