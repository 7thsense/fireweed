# Fireweed Queue v0.23.3 public preview

v0.23.3 hardens the complete public storage matrix release surface: CI binds
the full matrix on the release path, public-clone quickstart is unblocked,
workspace clippy is green after the object-log authority demotion, and
release-gate documentation distinguishes local smoke from tag evidence.

## Highlights

- **Storage-matrix gate on release validation** — `scripts/ci/storage-matrix-gate.sh`
  is wired into release/deployment release-gate paths so the 15-cell matrix is
  not an offline optional check.
- **Anonymous quickstart** — public-clone / anonymous operator quickstart
  blockers cleared; clone-proof tracked and closed.
- **Object-log authority surface** — public `ObjectLogAuthority` is
  `NativeConditionalWrite` only; tests and benches no longer reference a
  removed Postgres pointer authority. Watermark unit-test helpers restored so
  `clippy -D warnings` stays green on lib tests.
- **Release evidence docs** — local smoke vs tag-bound TP-002 evidence gates
  are distinguished in operator-facing release-gate documentation.
- **Density harness** — filesystem object-log selection fix for the density
  evidence path (harness repair under `pqueue-c989bc20`).

## Verification
