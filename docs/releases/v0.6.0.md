# pqueue v0.6.0

## Highlights

- Adds the supported `objectlog/hybrid` projection profile, combining the
  segmented object-log command authority with a SQLite-backed durable projection
  and in-memory hot read serving.
- Wires `PQUEUE_PROJECTION_BACKEND=hybrid` for the object-log runtime profile,
  including Helm/static validation coverage for the hybrid deployment shape.
- Adds recovery and request-id replay coverage for the hybrid profile so
  owner-local restarts hydrate from SQLite and replay only the retained
  object-log tail.

## Validation

- `cargo fmt --check`
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- `cargo test --workspace --all-features`
- `scripts/ci/release-gate.sh`

## Operator Notes

Use `PQUEUE_LOG_BACKEND=objectlog` with `PQUEUE_PROJECTION_BACKEND=hybrid` and
the existing `PQUEUE_SQLITE_PROJECTION_PATH` setting for the local durable
projection file. Segment expiry remains disabled for this release unless a
separate object-store snapshot strategy is added and validated.
