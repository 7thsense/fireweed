# Fireweed Queue v0.29.0 public preview

v0.29.0 closes Snorri-discovered validate-before-apply races on async objectlog
products and documents NativeConditionalWrite endpoint compatibility (Garage
unsupported). E3 TP-003 four-bound binding scaffolding is restored on LogEngine.

## Highlights

### Correctness (Snorri)

- **Lease resolve under queue gate** — `FinalizePort` / `RenewLeasePort` no longer
  render claimed leases outside `KeyedQueueGate` then plan under the gate.
  New `AsyncComposedBackend::finalize_outcomes` and `renew_item_ids` hold
  render + plan + commit on one permit (fireweed-c8e0a7a5).
- **Competing claim/finalize** — claim_by_item_ids prepare runs under
  `submit_operation` with append/apply so illegal lifecycle commands are not
  admitted into the durable log (fireweed-2be744bd).
- **Regressions** — `claim_then_immediate_commit_transition_succeeds`,
  `competing_workers_claim_finalize_never_illegal_lifecycle` on objectlog sqlite.

### Object-log authority

- **Compatibility matrix** — `docs/operator/object-log-authority-compatibility.md`
  (AWS/MinIO/filesystem supported; Garage v2.2.0 unsupported for multi-writer).
- **Open errors** — S3 open failures that look like missing create-only
  preconditions name the endpoint and the NativeConditionalWrite requirement
  (fireweed-2aefefbb).

### E3 / TP-003 bind (partial)

- **Emitter** — `e3_governed_transaction_evidence_matrix` (env-gated 48-row
  emission) wired from `scripts/perf/tp002-e3-s3.sh`.
- **Shared probe** — LogRead + RequestIdReplayProbe on objectlog memory/sqlite
  via `request_id_probe`.
- **Semantic verifier** — prior 40 focused E3 contract tests remain green.
- **Residual** — full live 48-row + cost/ack ledger under `pqueue-802be88f` /
  `pqueue-c4e5f691` still requires operator MinIO release run.
