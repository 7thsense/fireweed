# pqueue v0.14.0

## Highlights

- objectlog/hybrid-strict and objectlog/hybrid-async now fail closed when a recovered projection image is behind a deleted manifest prefix, and they resume from the retained floor/head replay path once the retained range is available again.

## Release Note

- `pqueue-c33c367e` was evaluated for this change and does not widen the delete-safe envelope. The stale-writer fence still comes from the permanent head CAS, and the retained-floor replay path remains the recovery source for deleted-prefix recovery.
- Dependency `pqueue-8928baec` remains the governing branch-inheritance fix, and the retained-floor/head release evidence is captured in [.ddx/executions/20260714T062700-afb4519c/branch-inheritance-release-verification.md](/home/erik/.cache/ddx/exec-wt/.execute-bead-wt-pqueue-794856a9-20260714T062700-afb4519c/.ddx/executions/20260714T062700-afb4519c/branch-inheritance-release-verification.md).
