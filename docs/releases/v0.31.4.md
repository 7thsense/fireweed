## Cut contents

### Performance (10k campaign)

- **`claim_finalize_push_cycle`**: one FULL fsync for claim + finalize + lifecycle push
  (replaces two-seal claim-then-commit worker loops for high-throughput paths).
- Atomic commit path: no double envelope clone (`append_encoded` + owned apply); skip
  control-plane definition fetch when no gates/request-id.
- Projection: one-pass dual index insert; SqliteLog WAL+FULL with larger cache/mmap.
- Group-commit on concurrent log appends (stress: 64 appends → 2 seals).
- Product-cell amortization gates remain green; pure commit software floor @512 often ≤0.1 ms/entry.
