# pqueue v0.19.5

v0.19.5 is a batching and maintenance-efficiency release. It preserves the
v0.19.4 reliability fixes while removing work that scaled with the number of
records where the storage layer already supports set-based operations.

## Changed

- SQLite typed-index validation and insertion now operate in bounded batches
  instead of issuing scalar work for every record.
- Turso purge, lease renewal, and finalization validation use bind-safe,
  set-based chunks while retaining request-order validation and transactional
  rollback semantics.
- In-memory lease-expiry maintenance uses an ordered expiry index, so reclaim
  paging is bounded by the requested page instead of the resident item count.

The associated regression tests compare structural operation, statement, and
page counts at increasing batch sizes. They do not use quiet-host assumptions
or fixed wall-clock performance thresholds.
