# Fireweed Queue v0.30.0 — pre-S identity reservation (P17v)

Status: **reserved identity, not a cut release**. This note freezes public
package/version identity `V = 0.30.0` before candidate-source freeze (`S`). It
records policy, inventory commands, and expected paths only. It does **not**
claim an executed pass, promote evidence, create tag `v0.30.0`, or treat the
live `.ddx` tracker as product authority.

## Reserved identity

| Coordinate | Value | Treatment |
|---|---|---|
| SemVer `V` | `0.30.0` | Next unused package identity after `0.29.3` |
| Reserved tag name | `v0.30.0` | Reserved only; **must not exist** until product-ready `P20pr` |
| Workspace package version | `0.30.0` | Release-synchronized (`Cargo.toml` `[workspace.package].version`) |
| Pre-S note path | `docs/releases/v0.30.0.md` | This file |

Storage-campaign `P20` does **not** create `v0.30.0`. Product-ready `P20pr`
alone may create annotated tag `v0.30.0` pointing exactly at evidence commit
`E`. Candidate-source freeze `S` is selected later by `P17s` and is not this
bead's output.

## Policy

1. **Synchronized sources** move to `V` together: workspace package version and
   any public artifact coordinates that `list-public-version-sources.sh`
   classifies as `release-synchronized`.
2. **Independent Helm defaults** stay on the chart's own source policy
   (`charts/fireweed-queue/Chart.yaml` `version` / `appVersion`, currently
   `0.6.0`). Release packaging may override both to `V` only at package time.
3. **Independent tool coordinate**: `crates/fireweed-bench/Cargo.toml`
   unpublished package version (`0.3.1`) is **not** synchronized to `V`. Bump
   only under that package's own policy.
4. **Independent gate-set identities**: JSON pointer `/version` in
   `scripts/ci/public-release-gates.json` and `/version` in
   `scripts/ci/public-release-gates-ci.json` are P13a-owned gate-set identities.
   Each changes iff that manifest's governed content changes; neither is
   rewritten to package SemVer `V`.
5. **Tag reservation**: do not create, move, or push `v0.30.0` from storage
   campaign work. Local and remote absence of the tag is required until
   `P20pr`.
6. **No unexecuted pass**: this pre-S note must not record gate results,
   evidence digests, or tracker close authority. Later beads own measurement,
   promotion (`E`), and publication.
