# Fireweed v0.31.32 — current upstream dependencies

This source-preview prerelease updates the dependencies that were behind a
stable release. It does not change the public cell. It is not a governed
product-ready P20pr deployment qualification and does not claim a new capacity
pin.

## Updates

- `axon-esf` moves from tag `v0.3.2` to `v0.4.2`.
- `fjord-broker` moves from tag `v0.1.3` to `v0.1.5`.
- Direct `base64` moves from 0.22 to 0.23.1.
- Compatible crates.io updates in the lock include `aws-smithy-runtime`
  1.15.0, `aws-smithy-types` 1.8.0, `aegis` 0.9.19, and `rand` 0.10.3.

## Left on the current pin

- Turso stays the patched 0.7.2 bundle. 0.7.2 is still the latest stable
  release. 0.8.0-pre.11 is a pre-release, and the vendored checkpoint,
  page-cache, and index patches are not replaced by it.
- `object-log` stays the vendored 0.3.1 tag, which is the latest tag, plus
  the local manifest-publication patches recorded in `vendor/object-log/UPSTREAM.md`.
- `heimq` stays tag `v0.1.2`. Tag `v0.1.6` exists, and `fjord` 0.1.5 still
  requires `v0.1.2`. Using both tags at once duplicates `heimq-broker` and
  breaks the server build.
- Every other direct crates.io dependency was already on its latest stable
  release.
