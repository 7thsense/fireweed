## Intent Summary

Fireweed is a batch-centric durable priority queue. Accepted work is not lost, an item has one active lease, and retries resolve by request identity. Seventh Sense is the first workload, not the data model.

The last written storage law, dated 2026-09-17 and repeated on the vision, the PRD amendment, ADR-012, ADR-016, and `storage-authority-manifest.json`, is twelve cells: logs `memory | postgres | filesystem | s3` crossed with projections `memory | turso | postgres`. Nine are Class A. Three memory-log cells are Class B. SQLite is retired. Strict is required on all twelve. AsyncProjection is the object-log deferral (six positives, six pre-I/O rejections). Turso is the default projection and is not the command log.

The queue contract under that law is unchanged: priority, eligibility, leases, idempotent batch ingest, group and cohort claim, recurring rearm, and at-least-once delivery.

Scale targets in the PRD are exact counts, a 10M resident queue, 1000 cold queues plus one hot queue, and queue-global progress. Absolute throughput is a capacity observation for a named topology, not a portable pass bar.

## Current state of the tree

`v0.31.30` is an honest source preview of one cell.

- `StorageConfig::validate` accepts only S3 log × Turso projection. The other eleven axis pairs return `RETIRED_STORAGE_CELL` (`crates/fireweed/src/lib.rs:1143`, `:1206-1228`). `legacy_selector_enumeration_rejects_retired_cells` asserts `public_cells == 1` and `retired_cells == 11` (`:1568-1569`).
- `ResponseBarrier` and server `ResponseBarrierSpec` have only `AsyncProjection` (`crates/fireweed/src/lib.rs:879-881`, `crates/fireweed-server/src/lib.rs:768-770`).
- On that cell, push, batch, group claim, whole-cohort claim, rearm, and push/commit request-id replay run through the shared public-interface suite opened with `StorageConfig::s3_turso`. `projection_control` verify/delete/rebuild replays the S3 log (`s3_turso_projection_loss_rebuilds_from_durable_log`). Public reads may wait coverage. Ordinary `claim` polls applied rows and may be empty.
- The release notes record an untraced eight-cycle campaign on ancestor `bcef51f9`: about 9,507 completed lifecycles/s, stretch 12.5k missed, not a qualification pin (`docs/releases/v0.31.30.md:27-33`).
- The library gate and the server are not the same product. `Server::validate_for_start` does not apply `RETIRED_STORAGE_CELL` (`crates/fireweed-server/src/lib.rs:992-1025`). `start` still matches `LogSpec::Memory` × `ProjectionSpec::InMemory` and other families (`:2261`).
- Twenty-five beads are open. They are the Turso packing and 10k-every-phase epic, plus at least one postgres parity item. None is an alignment review. They were not updated.

The September amendments and the binary cannot both be the current product. The bodies under those amendments still describe a third, older product (20 cells, or the 15-cell readiness matrix, with SQLite and Strict).
