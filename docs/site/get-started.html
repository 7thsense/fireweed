Get started

Fireweed v0.30.0 is the current workspace package identity. Clone the repository; crates.io publication is deferred.

Prerequisites: Git, rustup, a C toolchain and CMake for native crypto dependencies. Queue::ephemeral_disk needs no services; production uses Queue::s3_turso with S3 and PostgreSQL.

Embed Rust

clone and run the lifecycle examplesh
git clone https://github.com/7thsense/fireweed.git
cd fireweed
# Requires rustup; toolchain from rust-toolchain.toml
cargo run -p fireweed --example queue_lifecycle

The public entry point is fireweed::queue::Queue: Queue::s3_turso (production), Queue::ephemeral_disk (development and tests) and Queue::postgres (feature postgres, the reference store). Walk basic lifecycle then scheduled delivery.
