Rust crates

fireweed-dsl reads and checks documents. fireweed-dsl-postgres runs them. Generate the full docs with cargo doc -p fireweed-dsl -p fireweed-dsl-postgres --no-deps --open.

Executor functions

fireweed_dsl_postgres is a set of async functions over a tokio_postgres::Client. They hold no state between calls: each reads the space's schema from the database, checks the program against it, and runs it. Each returns fireweed_dsl::Result.

FunctionDoes
apply_schema(&mut Client, tenant, space, &Schema, expected: Option<i64>) -> AppliedCreates a space, or applies an additive change. expected is the version being replaced, None for a new space. An identical schema is accepted unchanged.
get_schema(&Client, tenant, space) -> Option<Schema>The stored schema of a space.
execute(&mut Client, tenant, space, &Program) -> ResponseRuns a program as one transaction. Retries a deadlock up to 5 times, then fails with Contention.
execute_batch(&mut Client, tenant, space, &[Program]) -> Vec<Result<Response>>Runs up to 64 independent programs in one transaction with one commit, each under its own savepoint. Results come back in order.
sweep(&mut Client, tenant, space, batch: u32) -> SweptWrites back lapsed leases and deletes what retention has expired, at most batch rows per object.
