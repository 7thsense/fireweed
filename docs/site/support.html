Support boundary

Supported means maintainers accept correctness reports against the documented contract and intend to preserve configuration compatibility within each supported 0.x minor line. It is not a 1.0 SemVer, SLA, capacity, or production-readiness claim.

The public API is fireweed::queue::Queue (API-007). There is one production storage composition and one reference store.

ConstructorStatusNotes
Queue::s3_tursosupportedProduction: S3 object log (native conditional write), disposable local Turso projection per owned queue, PostgreSQL queue leases. Provider brands are not product SKUs.
Queue::postgressupportedNative PostgreSQL reference store; opt-in cargo feature postgres.
Queue::ephemeral_diskdevelopmentThrowaway on-disk store for development and tests; nothing survives shutdown.
