Status and support

Fireweed is two crates in one repository. PostgreSQL 18 is the first and currently only executor.

ComponentStatusNotes
fireweed-dslin repositorySchema and program types, YAML and JSON reading, and the checker. No I/O.
fireweed-dsl-postgresin repositoryThe executor for PostgreSQL 18: DDL from a schema, and one SQL statement per DSL statement. Its tests run on PostgreSQL 18.
crates.ionot publishedBoth crates set publish = false. Depend on the git repository.

What the executor's tests cover

  • The DDL and indexes each schema creates, and additive changes.
  • Every statement, rejections rolling back while keeping the request record, replay and fingerprint conflicts.
  • Concurrent claims from several connections never leasing an item twice.
  • Lease expiry, reclaim and attempt exhaustion under a fixed fireweed.now.
  • Merge rules, expectations and stepped updates.
  • That claims, indexed selects, keyed updates, grouped counts and sweeps over 5,000 items do no sequential scans of the table.
  • That requests issued before the space's horizon are refused, also after their records are swept.
  • That programs in a batch commit, reject or fail independently.

Not in v1

  • Cohorts, group keys and per-group ordering.
  • Dynamic gates and metadata blockers.
  • Recurrence beyond release with after.
  • Joins.
  • Maintained counts by state: an aggregate over a whole queue needs an index-backed condition.

Support

Support is best-effort through public issues, with no service-level agreement. See SUPPORT.md and contribute.
