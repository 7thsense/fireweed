Install path

release artifactschecksums
OWNER=<github-owner>
REPO=fireweed
TAG=v0.27.0
VERSION="${TAG#v}"
DIST_DIR="release-${TAG}"

gh release download "$TAG" --repo "${OWNER}/${REPO}" \
  --pattern "fireweed-${VERSION}-*.tar.gz" \
  --pattern "fireweed-queue-${VERSION}.tgz" \
  --pattern "fireweed-service-image.txt" \
  --pattern "fireweed-queue-helm-chart.txt" \
  --pattern "SHA256SUMS" \
  --dir "$DIST_DIR"

(cd "$DIST_DIR" && shasum -a 256 -c SHA256SUMS)
helm installobjectlog path
NAMESPACE=fireweed
RELEASE=fireweed
IMAGE="ghcr.io/${OWNER}/fireweed-service"

kubectl create namespace "$NAMESPACE"

helm install "$RELEASE" "$DIST_DIR/fireweed-queue-${VERSION}.tgz" \
  --namespace "$NAMESPACE" \
  --set image.repository="$IMAGE" \
  --set image.tag="$VERSION" \
  --set storage.log.backend=objectlog \
  --set storage.projection.backend=inmemory

Storage axes

orthogonal

log backend

Chart values may expose objectlog and postgres. Prefer supported object-log compositions unless you knowingly operate outside the support contract.

projection backend

Chart values may expose inmemory, sqlite, hybrid, hybrid-async, and postgres. Unsupported pairings fail at startup.
