Contribute

Fireweed is a maintainer-developed open-source project. Collaboration happens through issues, not code pull requests.

Issues are welcome

Bugs, feature requests, documentation problems and usage questions. Include the schema and program documents, the PostgreSQL version, the expected and actual response, and a minimal reproduction.

Open an issue →

Code contributions are not accepted

Pull requests, patches and other code contributions are not accepted. Small reproduction snippets in issues are offered under MIT OR Apache-2.0.

Security

Do not disclose vulnerabilities in public issues. Use GitHub private vulnerability reporting on the repository's Security tab. See SECURITY.md.
